# 沉香品牌官网 V1.0 素材使用说明

## 当前交付
- `assets/hero.svg`：首页 Banner 的可直接使用的矢量占位图。
- `assets/product-chips.svg`：沉香切块示意素材。
- `assets/product-sticks.svg`：沉香线香示意素材。
- `assets/article.svg`：沉香知识文章示意素材。
- `assets/concepts/homepage-visual-reference.png`：AI 生成的品牌网站视觉**参考稿**，不是可直接拆分上架的产品照片；参考稿中文字可能不准确，禁止将其文字直接用于正式网站。

## 上线前需补充的实拍图片
1. 首页横幅：真实沉香原料与熏香场景，横版建议 1920×800。
2. 产品图片：切块、勾丝、线香、珠串及香具各至少 3 张（正面、细节、使用方式）。
3. 场景图片：茶室、书房、电熏炉使用图，建议横版。
4. 企业资料：实际门店或工作室、负责人认可的品牌与营业信息、联系方式。

## 使用规范
- AI 图片和 SVG 均不应被描述为实际库存、真实产地或品质证明。
- 不以“安神治疗”“保健疗效”等未经证实的医疗功效宣传产品。
- 如采购第三方摄影，逐张核查商业使用许可和署名要求。
- 真正商品详情优先上传与所售批次一致的实拍照片。
